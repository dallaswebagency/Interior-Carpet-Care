# Image prompts for Interior Carpet Care

Save each file into the `images/` folder with the exact filename shown. Use the aspect ratio listed.

Every Google Flow prompt ends with the same style line: natural daylight, realistic photograph, warm and clean, no text, no logos, no watermarks, no faces in focus. Flow adds a small star watermark near the bottom-right corner, so each prompt asks for a calm, uncluttered bottom edge. If a star still shows, crop about 140px off the bottom.

## Logo prompt (for ChatGPT image generation)

Paste this into ChatGPT, then save the result as `images/logo.png`. Ask for a **transparent background** PNG, or a plain white background that you can remove.

> Design a clean, modern logo for "Interior Carpet Care", a family-run carpet, upholstery and tile cleaning company in Cochrane, Alberta, Canada, trading since 1992. Horizontal layout: a simple square or rounded-square emblem on the left, with the company name on the right in a friendly, confident, bold sans-serif (similar to Bricolage Grotesque), with a small spaced-out line underneath reading "COCHRANE, ALBERTA" in a light uppercase font. The emblem is a stylised woven carpet pattern made of crossing dashed stripes, hinting at a clean fibre texture. Colours: deep pine green (#1F3B34) as the main colour, with accents of terracotta clay (#C4572F) and warm saffron yellow (#E9A93B). Flat vector style, no gradients, no 3D, no shadows, no stock icons, no mascots. Must stay legible when small (around 54px high) on a light cream (#F4EEE3) header and on a dark green footer. Transparent background, tightly cropped with even padding, high resolution.

Tip: also ask for a second version in white and saffron for dark backgrounds if you want it on the green footer.
